# v1.9.0：账号定位、历史与表达学习

第四批把单公众号的账号定位、历史索引、人工改稿学习、范文和效果记录接入现有工作台。选题、写作、大纲、选段修改与整体编辑在每次调用前读取当前账号参考；本篇明确要求优先，公众号的语气、体裁与论证主线保持。

## 功能与使用

- 顶部“账号与学习”维护账号受众、方向、表达和禁用事项。历史索引完整保存主题、角度、读者问题、结论和状态，可以检索、分页与编辑。旧文只从已有字段建立索引，缺失信息显示待补充，不付费重读全部旧文章，不重写正文或人工决定。
- 历史参考重点近30天、加强近7天，也检索相关旧角度；同主题的新证据和新角度仍可写，不设题目黑名单。调用上下文有条数和字符上限，实际选取与省略数量可查看，完整索引仍在本地。
- 只有有明确连接且正文确实不同的AI稿／人工定稿对才能学习。AI修改、采用AI候选或仅点击定稿不算人工偏好；重复对不重复计数。保存原稿、定稿、来源、栏目、次数、时间及状态。提炼使用既有研究路由，每次最多五条，默认本栏目软参考；90天权重减半，过低后不再使用。明确确认后才固定，扩大到全账号需另行操作。后续学习不会重新启用已撤销或停用的同一规则。
- 支持偏好编辑、停用、删除、撤销使用及撤销上次账号修改。编辑已固定或全账号规则会回到原栏目软参考；账号版本冲突返回提示，不能覆盖另一页面的保存。
- 范文可粘贴、从网址或文件导入，沿用现有读取、进度、事件和取消机制。提炼后待作者确认；写作只接收抽象表达、结构和节奏，不接收范文原文。范文中的事实、人物、经历和观点不能作为本篇证据。
- 效果可手动或UTF-8 CSV记录，关联文章、发布时间、统计时点和完整小时窗口。相同栏目与窗口、每个指标至少五篇独立文章才显示样本均值与范围；同文多次记录不凑样本，未知值不记零，不推因果、不覆盖准确性。CSV整批校验后提交，错误行不会留下半批记录。不连接公众号账号，不新增凭证。
- “本篇使用记录”展示实际调用提供的账号定位、偏好权重及来源、范文表达、历史和效果。参考进入输入不等于模型一定遵从，记录同时区分请求返回与未完成。独立事实核查不接收这些软参考。
- 账号在生成过程中变更，旧上下文结果保留待处理，停止自动写入与后续链条。保存事务和候选采用再次核对账号版本；整体候选与选段建议不能因文章历史恢复而绕过已撤销的账号偏好。

## 数据、验证与限制

沿用SQLite和文章版本保护。迁移前建立并校验数据库备份，只新增账号、账号历史、主题索引和使用记录表；文章新增索引字段可选，不重写旧正文、编号、引用或人工决定。账号状态独立于文章历史。原有研究限额、一次材料修正、独立事实核查和最多两轮整体编辑保留。

本地完整后端545项通过；最终补充的断连用量、撤销后再次学习等边界及相关编辑回归35项通过。界面初次完整运行覆盖选题到导出、整体候选、恢复和人工改稿学习，在快速切换页签处发现操作被忽略；修复为排队执行后，定向实际界面验证通过历史编辑、未知效果值、CSV原子失败、使用记录及1440/1100/390宽度。最终提交还须以其自身CI中的完整离线流程为发布依据，不能将早期失败拼成通过；最终发布核对写入后续交付归档。

本批没有付费模型验证，也没有探测外部服务。现有累计69/76次请求及失败原样保留，剩余7次没有使用或挪作第四批。离线模拟验证功能和输入边界，不证明模型一定学到准确偏好或改善文风。范文提炼可能仍需人工修订，效果只作样本描述；既有ACL与M1未通过的实际成稿结论保持不变，见[v1.8.0记录](RELEASE-1.8.0.md)。

账号参考默认空白，升级不修改用户模型、Key、路由及研究参数。私有数据库、文章、原始响应、学习资料和诊断不随仓库发布。排版继续保留下拉框、颜色圆点、参数输入和手机预览。版本切换后旧页面需要刷新。
