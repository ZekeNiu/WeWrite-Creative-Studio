# 工作台如何执行 WeWrite

原生化分三批交付。2.0 恢复创作核心；2.1 接入账号学习和原生粘贴排版；扩展动作由后续版本接入。上游不是单一写作 API，而是技能、执行环境和确定性命令的组合。保持这些条件一致不意味着逐字输出一致。

## 固定上游与真实执行

固定 `4.2.1 / e8df474ea8d9fd1b06b474115cee568dc46c9ab2`。`vendor/wewrite/UPSTREAM_MANIFEST.json` 对原始文件保存 SHA-256（统一 CRLF/LF）；每次执行校验。工作台直接导入所附源码；命令在独立子进程中执行同一份源码，不依赖机器上碰巧安装的其他版本。

每次执行有独立 `data/native/<execution_id>`、`WEWRITE_HOME` 和上游 run_id。加载完整主技能、当前模块、必读参考和所选人格，记录文件哈希；模型可以使用 Read、Find、List 补读其他参考及完整材料，通过 Write、Edit、受控 WeWrite 命令保存实际产物。WebFetch 复用现有原文读取器，不将搜索摘要当全文。

三种现有文本协议均支持多轮工具对话。Responses 保留全部返回项目及推理内容；Messages 保留工具及签名块，Chat 保留 tool_calls 和对应结果。连接测试分别检验文本与两轮工具往返，不将文本成功当成 Agent 成功。协议实现参考 [OpenAI 的推理与工具上下文说明](https://developers.openai.com/api/docs/guides/reasoning)。没有工具调用时明确失败，保留产物，不退回旧写作提示。

## 界面与上游的关系

| 界面动作 | 上游过程 | 交接产物 |
|---|---|---|
| 选题 | wewrite-topic | topics.yaml |
| 资料整理 | wewrite-write 任务书、主张与内容增强准备 | brief.yaml / claims.yaml / sources.yaml |
| 大纲 | wewrite-write 框架与章节推进 | brief.yaml.sections |
| 写作、选段修改 | wewrite-write | draft.md / replacement.md |
| 审核、整体编辑 | wewrite-review，最多两轮 | assessment.yaml / review-report.json / article.md |
| 配图方案 | wewrite-visual 提示词模式 | images.json |

七阶段界面是暂停与人工操作的边界，不另立写作标准。自动继续沿用每篇设置；选题候选、人工决定、资料使用要求和完整原文可被模型读取。默认不调用原先的强化研究、论证综合、逐段事实检查或额外编辑循环。素材页仍可单独启动强化研究，结果保留在同一文章和来源集合中。

原生主张不会再因缺少本地强化研究的额外评判字段而被自动降级。旧记录及其问题处理仍可查看；人工决定、来源存在性、引用、有效文件、权限和版本冲突继续由代码检查。

审稿输入是当前稿、简明待处理事项与原文路径，详细旧报告不反复回灌。编辑报告必须实际由上游 content-eval 产生，并与稿件内容绑定；后改稿件会使报告失效。通过门槛直接采用上游计算，轻微建议不触发额外改写。通过后执行上游封存；未通过保留待处理状态。

## 数据与费用

SQLite 是人工状态的权威来源，上游文件是该次任务的输入副本与产物。只有文章和账号版本仍匹配时才事务回写；修改候选单独保存，采用时再次检查。取消、中断或冲突均保留本次文件，可在“上游执行记录”查看。旧文章继续创作时才建立副本，不迁移另一部署，也不自动付费重读历史。

上游按网址和主张建立账本，适配层将同一资料的多条主张归回工作台稳定来源编号，保留主张记录。被用户排除的资料不能通过网页读取悄悄重新采用。技能、原文和任务状态文件受路径与写入权限保护；模型不能运行任意 shell、读其他任务或改写凭证。

总请求与金额限制独立于搜索次数；文本、工具内付费搜索、图片、连接测试、失败请求均留用量记录。金额上限需配置人民币单价，未知费用不记零；发生未知费用后不能继续凭估计消耗金额上限。并发请求先预留费用。没有自动网络重试，旧强化研究的格式重试也计入总限额。本轮诊断的 8 次／20 元不是产品默认值。

## 验收边界

离线模型返回是合成数据；真正运行工具循环、文件操作、上游命令、版本保护和界面。这证明软件交接与恢复行为，不证明真实模型会遵守所有技能、也不证明文笔优于旧版。真实质量对照需要相同模型、参数、人格、任务、材料及执行条件，并单独报告结果。未知中转价格不能用其他供应商官网价格代替。

## 账号和排版（2.1）

账号设置映射为上游 style.yaml，历史写入 history.yaml，已启用偏好按明确改稿对投影为 lessons，再调用上游 learn-edits --summarize。置信度、重复提升和衰减直接使用上游算法，不再使用自定义90天半衰期。栏目范围先筛选，上游人格／框架等范围继续生效；停用与撤销记录不重新启用。人工编辑规则会重置学习次数，来源记录仍保留。

人工改稿学习执行完整 wewrite-learn，通过真实 diff、文件读写和类型化模式，保留原稿／人工稿对，用户确认仍由界面完成。导入范文用上游本地提取，不调用模型；按栏目和类型选择最多两份，提供真实表达片段及所有权标记，不允许复用私人经历。旧范文无需付费重处理。

排版复用 make_paste_safe 和 validate_html，清洗保留 leaf；界面显示兼容性结果。封面独立保留在分享包和图片栏，不默认加入正文。配图数量为上限，原下拉框、颜色圆点、参数和手机预览不变。搜索和原文读取限额跨原生阶段累计。
