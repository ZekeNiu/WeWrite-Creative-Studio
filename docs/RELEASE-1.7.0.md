# v1.7.0：按问题研究与来源笔记

第二批将研究流程接入稳定任务书：按问题轮转查询、筛选候选、追踪引文、回读章节并保存逐源笔记。来源定位、事实支持与回答完整性分别检查；任务停止或人工继续不会被记为资料充分。

## 改动

- 在原检索预算内分配问题与渠道，保留候选处置、真实阅读范围及过程事件。
- 同源最多四条证据共用核查原文，各条独立绑定原文、主张、边界与唯一判断；已有材料最多修正一次。
- 汇总只使用核实后的证据。实际入口、读取地址、范围、身份匹配和元数据出处进入核查上下文，并参与材料依赖和证据缓存失效。
- 明确原始发布者、公开副本、翻译转载与论坛发言的区别；撤去定性词表自动裁决，保留原文定位、数值时间边界和已验证的物理量错配检查。
- 结构化响应必须唯一完整。格式无效的已完成响应最多按同一输入请求三次；取消、连接、权限和余额故障不自动重试，原始失败保留。
- 保留用户模型、研究参数、引用编号、人工决定、数据库及原排版布局。后端版本与应用、锁文件及预构建界面同步为1.7.0。

## 验证与发布边界

- 最终实现通过507项后端测试和完整离线界面流程；包含取消、预算、缓存失效、来源归属传递、引用、保存冲突、导出及恢复。最终实现自身CI成功，正式发布提交须另行完成自身CI。
- 当前实现的两次定向真实核查分别将译文判为二手来源、官方原页判为一手来源；同一旧主张的适用范围仍有模型判断分歧。这是归属诊断，不是完整任务通过。
- 一道未参与调试的新题读到原始论文全文，但20次请求内未完成外推边界说明，第21次发出前被阻断；第二道题未启动。该题仍记未完成，没有可验收的资料充分结果。历史失败与不同实现结果不拼成通过成绩。
- 用户指出无限增加规则或要求模型穷尽成功不合理。依此调整发布判断：确定性的保护必须可靠，语义任务使用合理上下文、既有独立核查和有限修正；少量真实运行用于暴露能力与成本边界。安全停下的模型失败不自动阻止软件版本发布，不能反过来把失败记为成功。

重复笔记与全面审查仍有成本空间；表达语调曾被卷入证据缺口，否定边界和条件范围仍可能误判。第三批将收拢调度与提示词职责，复用现有核查，不另加审核层或文章例外。此版本不宣称普遍准确、无人值守必成或真实新题全通过。

本次真实验证累计台账保留56次请求，授权上限76、单题20；剩余额度不触发自动重试。费用缺失仍为未知，配置未改变，诊断与私人材料不随发布提交。

## 升级

发布前核对活动任务并备份数据库及私有文件记录；空闲时由现有启动器启用新版，复核服务版本、提供的界面资源、重复启动复用及私有记录一致性。旧页面需刷新。备份与运行核对明细只保存在本机。

第三批编辑和第四批历史/偏好仍按[路线图](QUALITY-ROADMAP.md)推进；它们同样采用有限验证，不以穷举语义正确性为门槛。
