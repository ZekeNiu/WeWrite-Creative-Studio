# v2.0.0：恢复上游创作核心

默认创作从单次文本生成改为完整技能与多轮工具执行，保留七阶段人工控制。固定上游版本及文件清单，实际调用所附源码；支持按位置补读原文、稳定引用、受控上游命令、真实编辑报告与通过后封存。

移除默认强化研究、论证综合、分段核查和额外改稿循环。编辑不接收整份旧审核报告；原生主张不经过旧本地语义门槛再次降级。候选与原稿分开，轻微建议遵循上游通过语义。文章及账号版本冲突、取消和已撤销参考不能被新执行绕过。

增加三协议工具往返测试、总请求／金额限制、上游读取记录与保留产物查看。测试入口限定正式 tests 目录。账号学习、排版和扩展能力继续按后续两批交付，详见[执行架构](NATIVE-WEWRITE.md)。

本批新增付费模型请求为 **0**。现有文本单价未知，未进行付费质量对照；模拟内容表现不作为真实质量结论。个人数据、凭证与诊断只留本机。

本地验收：560 项后端检查通过；前端构建通过；完整离线界面通过选题、素材、大纲、写作、复审、候选采用／拒绝、人工定稿、学习、效果、恢复、保存冲突与多种窗口宽度。新工具运行测试实际执行上游命令，未模拟命令成功。
