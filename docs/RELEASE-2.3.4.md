# v2.3.4 联网流程修复

节点模型与联网模型原本独立分配，但联网入口只在流程偏好中，导致切换选题／分析服务后仍可能使用另一服务搜索。本版在“节点分工”增加共用联网模型，创作页同时显示两类服务，搜索失败后的设置按钮直接定位联网配置。已有模型分配不自动改写。

## 修复与边界

- 原生创作与资料核实共用后备渠道顺序和失败分类。关闭后备后，后续工具调用也不切换；空结果继续尝试已启用渠道，每次实际尝试计入搜索上限。
- 开启后备时，搜索超时、断连、明确限流、HTTP 5xx、工具暂不可用或输出截断可转免费渠道。该任务后续阶段也不重发失败的付费搜索、不追加 Tavily。无结果时仍可按配置使用后备渠道。
- 认证、权限、余额、原因不明的 429、无效请求、拒答、异常响应、取消和预算限制仍会停止。没有新增自动付费重试，没有提高超时、请求数、金额或输出上限。后续文本分析仍受原任务预算约束。
- 区分搜索截断、未完成和服务端工具错误，保存安全错误码、实际结束原因、内部次数与用量；流式结束原因也保留。含来源的截断响应也不被误标为联网验证通过。
- 修正失败搜索次数保存顺序；搜索工具费为零也不能把未知 Token 费用记为零。
- DeepSeek Chat 工具调用采用与默认思考模式兼容的 `auto`，继续要求实际工具产物并保留一次纠正及预算。Messages 等其他接口保持原工具选择规则。搜索能力测试结论按新实现失效；DeepSeek Chat 工具参数变化使对应旧结论失效，其他能力不被整体清空。
- 排版导出的下拉框、颜色圆点、参数输入和手机预览布局保持原样。

## 使用

保存页面中未提交的输入后刷新。到“AI 服务 → 节点分工 → 联网搜索 · 所有环节共用”选择希望用于真实搜索的服务；其原生联网协议仍在“能力测试”中配置。节点与联网模型分别显示，切换分析模型不会自动覆盖联网选择。

暂时性搜索故障后的后备行为受现有开关、渠道启用状态与任务预算共同限制。免费渠道也可能无结果或不可达；这时保留未完成状态和已知诊断，不生成虚假的搜索成功。
