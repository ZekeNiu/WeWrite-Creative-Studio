# v2.3.6 任务状态与防休眠

任务运行框现在区分正在进行的外部请求与最近完成的动作。模型、检索、资料读取和图片请求进行中显示本次调用时长；模型回复、工具执行或资料读取完成后，才更新最近完成时间。流式内容尚在接收时仍显示本次调用持续时间，不把等待或开始执行当成已完成。旧任务记录无需迁移。

移除了 DeepSeek 内部检索费用提示；历史诊断里的同一句提示也不再出现在界面，其他搜索警告保留。任务状态与执行详情不再显示费用未知次数，调用及用量记录仍保存。主要工作区只显示生效服务和模型，不再展开“配置来源”；底部移除切换页面提示。当前步骤的运行提示使用与原工作台一致的浅绿色细边框信息框，错误与冲突提示沿用原配色。

Windows 后台会在任一任务等待执行或运行期间请求阻止空闲自动休眠，覆盖文章流程、素材导入、搜索检查、账号和扩展任务；最后一个任务结束或后台退出时解除。屏幕可自行熄灭，主动睡眠及合盖继续遵循系统设置。隔离合成任务验证了多任务、失败、取消、后台关闭及真实 Win32 请求的设置与解除。当前环境的 `powercfg /requests` 需要管理员权限，因此实际系统请求以 Win32 返回的前一状态核对；未修改系统电源计划。

离线后端全量回归 **667 项通过**，前端生产构建通过。桌面与窄屏视觉检查、完整创作流程、任务可靠性和模型设置浏览器检查均通过。旧验收脚本中仍按 v2.3.4 之前的搜索故障策略、v2.3.5 之前的输出参数字段命名和已移除的搜索次数控件检查的断言，已同步到现行行为并复测通过。本次未调用付费模型或修改个人文章。

实际工作区切换前确认没有活动任务。启动器将后台从 v2.3.5 安全切换到 v2.3.6；健康接口的运行及可用版本均为 v2.3.6，所提供的 5 个预构建界面文件与磁盘文件逐字节一致。再次运行启动器复用同一后台进程。已打开的旧页面需刷新以加载新版界面。
