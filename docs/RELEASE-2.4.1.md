# v2.4.1：提高素材与写作问题的匹配程度

搜索结果只有标题、不同论文被误判为重复检索、公开全文链接未被读取，会让素材收集停在泛泛的背景资料。本版修复这些路径，并让筛选明确说明资料能回答哪个问题、预期支撑什么内容。

- 检索按具体取证目标去重。同一问题下的不同 DOI、题名或比较需求独立执行；同一文献的 DOI 别名与同一目标换词仍会合并。
- 默认素材流程与深入核实共用文献身份补全。有稳定身份的候选可获得真实索引摘要；同一文献合并后再查询并复用缓存，查询失败保留原候选。摘要仍属于发现线索，实际主张遵循原有原文读取与校验流程。
- 读取馆藏页声明的 PDF，提取 Dublin Core DOI、论文题名等信息，核对是否为同一篇文献；优先提取文章主体，避免导航和无关弹窗影响正文判定。
- 深入核实按对应问题、研究对象、比较条件、预期贡献筛选，优先直接依据与反证，背景候选保留在记录中。默认素材工具同步记录阅读目的；材料已有有效主张时仍优先显示主张，否则可显示检索时的预期用途。
- OpenAlex 凭证或权限被拒绝时明确提示更新配置，同一任务避免换词重复调用失效渠道；普通零结果仍允许继续调整查询。

沿用当前 WeWrite 固定版本和界面布局，遵守已排除资料及搜索渠道设置。新增内容仅作用于此后执行的素材整理、读取和检索；现有文章不会自动重写。

公开来源实测使用隔离缓存与实际 HTTP 请求：

- [Gloucestershire 馆藏论文](https://eprints.glos.ac.uk/8211/)：基线只能提取文献信息，修复后取得身份一致的 16 页 PDF，提取正文 44,069 字符。
- [ACSM 专业文章](https://acsm.org/mythbusting-youth-resistance-training/)：基线被判为文献信息，修复后取得文章正文，提取 3,217 字符。
- 同一论文的 DOI 搜索候选补入真实索引摘要 687 字符，未标为已读全文。

本地 266 项相关后端回归、前端构建和素材页桌面／手机浏览器验收通过；上游清单校验通过。回归覆盖不同文献去重、错误 PDF 拒绝、已排除资料、截断搜索结果、凭证失败与普通零结果的区别，以及阅读目的不冒充已核实主张。

使用现有服务配置在独立数据库中完成了一次真实模型素材整理，选题为儿童运动训练敏感期。用时约 445 秒，23 次计量请求，得到 3 份全文、3 份摘要和 7 条主张，模型保存的核心缺口为空；阅读目的对应成熟阶段比较、训练反应及长期后果的区别。此样本验证了实际检索、读取和主张交接，不是与旧版使用相同输入的模型质量对照，也没有验证完整文章成稿质量。真实文章与用户配置未被改写，诊断副本与凭证不随版本发布。
