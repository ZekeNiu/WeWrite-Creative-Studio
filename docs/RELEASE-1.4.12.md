# v1.4.12 交付记录

本版修复操作可靠性、素材复核及数据一致性。保持创作目标、篇幅、资料渠道及原排版布局。本记录仅包含可公开的实现与模拟验收结论，不包含个人文章、凭证或本地诊断内容。

## 审查发现与处理对应

| 审查问题 | 本版处理 | 验证方式 |
| --- | --- | --- |
| 连续编辑使用过期对象，后保存覆盖前保存 | 队列执行时计算最新数组／对象；字段返回真实保存结果，失败保留输入 | 浏览器延迟请求下连续修改提示词、图注、数量与比例，失败重试及排版参数持久化 |
| 保存状态过早显示成功 | 统一跟踪未保存字段、排队保存和失败项 | 浏览器检查未保存提示及重试后的实际文章 |
| 历史恢复残留后来字段 | 业务状态完整替换、旧格式默认值、重新计算显示状态；恢复留版本，活动任务拒绝 | 早期快照恢复、后加创作意图、任务保护、损坏记录回归 |
| ZIP 暴露私人素材及内部备注 | 仅正文、排版、采用图片、实际引用文献；白名单及 share-v2 归档标识 | 私人全文／备注标记检查、组合引用、图片和归档一致性 |
| 设置部分写入，错误引用静默降级 | 全部验证后准备密文，同事务提交设置与密钥；引用错误拒绝 | 后段验证失败和数据库提交失败均保留旧值 |
| 引用校验不一致，Word 顺序错乱 | 共用引用解析；段落／标题／表格按文档顺序，图片／扫描提示 | 未知组合编号、Word 表格顺序、标题及图片样例 |
| 复核后旧证据残留 | 当前主张为权威，统一来源／研究摘要／写作上下文；只替换目标主张 | 定向复核、空结果清除目标旧证据、保留无关主张 |
| 原文定位被当作事实支持 | 支持强度、定位、理由、适用范围分别检查；有限支持需边界 | 固定质量样例、缺失字段、旧记录待复核 |
| 不使用或限定只保存决定，稿件没改 | 共用局部改稿任务，支持删除、逐项改动和未应用原因 | 准确／重复／重叠定位、无稿件约束、部分失败 |
| 自动应用及撤销可能覆盖人工编辑 | 任务开始与当前双重匹配；删除保留上下文，撤销不替换空字符串 | 整段删除、局部删除、无关人工编辑、相关内容冲突 |
| 部分成功显示全部完成 | 应用状态独立；每组最多 10 项，失败／取消保留已完成组，回执计入未执行项 | 21 项批量第二组失败／取消，部分应用仍待处理，撤销后回执更新 |
| 证据或决定变化后审核仍通过 | 审核签名包含有效证据及创作决定；显示重算不失效 | 证据／决定变更及重复显示回归 |
| 只核实 Q1 却因 Q2 继续搜索 | 评估、缓存、停止判断包含问题范围，完成目标后结束 | Q1 完成且 Q2 未完成、范围隔离、旧结论不能代替本次结果 |
| 素材入口／待办／限额不一致 | 稳定查找、核实、进入大纲入口；普通局限单列；本文上限持久化与统一优先级 | 刷新、逐条／批量核实、窄屏、长证据及处理回执 |
| 长期数据及更新可靠性不足 | 文章摘要搜索分页 20、历史分页 50；压缩历史及校验；数据库副本；过期缓存清理；锁文件指纹安装 | 新旧历史／损坏记录／副本失败、分页及旧接口、安装失败与活动任务保护 |

## 验收结果

- 全部后端测试：**267 项通过**。测试使用临时目录和模拟响应；不运行新增大规模付费模型对比。
- TypeScript 检查及正式前端构建通过，预构建 `dist` 随版本提交。编辑器包存在既有体积提示，不影响构建；本轮未进行全项目拆包重构。
- 当前构建的 Edge 浏览器完整流程通过：新文章、选题、上传文字、核实、保存本文上限及刷新、大纲、正文、审核、配图方案、连续保存、失败保留／重试、图片上传、原排版参数、复制及 ZIP、历史入口、局部排除与撤销。
- 桌面 1440、1100 和窄屏 390 宽度，无页面横向溢出；长证据、抽屉键盘焦点／Esc、禁用 sessionStorage、文章搜索与 20 条分页通过。已检查模拟界面截图。
- 新增 `.github/workflows/check.yml`：Windows 自动执行后端、类型／构建、已提交界面一致性和离线浏览器流程。不会上传个人数据或凭证。
- 本工作区启动前无活动任务，实际服务、界面版本为 **1.4.12**；静态文件逐字节匹配已构建文件，重复启动复用同一进程。文章、历史、设置及加密凭证记录的前后摘要一致。

## 升级与边界

旧页面请先保留未保存输入，再刷新加载新版。启动器安装与自检失败不会更新依赖标记；检测到活动任务时不会强制切换旧服务。

首次写入新历史前，在 `data/backups/` 创建并校验数据库安全副本；失败不启用新格式。新历史带格式和完整性校验，旧 JSON 继续可读，不自动重写或删除旧版本。回退旧程序需同时使用对应旧数据库副本，该副本不含附件与启用后的修改；先完整备份当前数据，详见 [使用说明](../使用说明.md)。

ZIP 只用于分享文章；旧归档不自动清理，旧包仍可能保留此前的较广导出内容。

**仍未实施**：完整备份／恢复界面，上游风格学习、跨文章选题去重、多平台改写等能力补齐，以及真实模型的系统内容质量／资料覆盖率比较。固定证据样例与模拟测试只验证规则和流程，不代表已达到上游内容质量。下一轮应以同材料、同模型的实际作品和检索覆盖对照确定差距，不能只补功能入口。
