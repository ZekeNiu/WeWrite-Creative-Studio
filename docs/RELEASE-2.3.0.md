# v2.3.0：选题诊断与交互可靠性

保留七阶段、参考侧栏和现有视觉风格。排版导出的下拉框、颜色圆点、参数输入和手机预览保留原位置。

## 选题、输入与恢复

- 选题共用一个执行函数：空状态的“寻找选题灵感”和已有候选时的“换一批选题”都先保存，再读取最新探索要求；快速连点不会重复启动。
- 文章增加可选 `input_drafts`，保存未采用主题、探索反馈、素材检索要求。输入草稿与采用主题分开，保存草稿不会让已有正文失效；旧文章无需迁移。
- 任务返回可选 `failure`，包含错误类别、HTTP 状态、供应商错误码、请求编号、等待时间、实际服务与模型、失败阶段。只保存安全的标识与解释，不保留原始服务响应或凭证。
- 区分超时、连接中断、明确限流、明确额度不足、权限和未知服务错误。HTTP 429 没有足够信息时明确保留“不确定”；历史记录不补猜具体原因。
- 失败卡仅在对应环节完整展示；其他页面使用简短提醒。重新运行针对实际失败阶段，过滤不适用的原始参数，自动配图失败可定位对应图片。
- 沿用原超时与任务预算，不增加模型自动重试、不静默切换模型，不提供工具会话断点恢复。重新运行会创建新任务。
- 内容完成状态与最近任务状态分别显示，补充当前动作、已发请求数、最后进展时间和实际生效模型。延迟打开文章、旧任务轮询及旧保存回调均核对归属。

## 页面调整

- AI 服务设置明确显式保存，关闭未保存表单时可保存、放弃或继续编辑；每个创作环节可直达对应模型分工。
- 窄屏顶部次要入口进入“更多”，阶段导航保留名称、状态及当前页标记，补齐控件名称和键盘操作。
- 下一环节按钮说明前置条件，浏览页面不代表采用或确认内容。已有文章时缩短首页介绍，文章卡显示实际字数与最近任务状态，搜索无结果单独提示。
- 素材主区突出结论和后续操作，核实记录折叠；侧栏聚焦选中素材的依据和关联。
- 大纲支持折叠、上移／下移和撤销删除。正文附近提供整体编辑和人工定稿，选段可直接打开 AI 修改；审核将已处理意见折叠。
- 目标读者与自定字数独立保存，推荐篇幅需单独采用。
- 配图生成入口统一，新生成图片保存 `plan_id`，展示关联及采用数量，提示方案或提示词变化；旧图片不猜测关联。
- 排版预览随保存自动更新，仅在失败时重试；最后环节隐藏自动继续开关。账号／扩展明确保存方式，任务状态使用中文，编号默认生成、技术细节折叠。
- 提高常用表单、操作、状态和辅助文字的字号与对比度。扩展任务完成后，等待文章刷新结束再开放后续操作，避免立即操作产生版本冲突。

## 验证与边界

后端全量 585 项检查通过；随后新增旧文章草稿兼容用例，相关 29 项定向检查通过。离线检查包含错误分类与脱敏、草稿不影响正文、旧任务兼容、自动流程重试参数和图片关联；浏览器覆盖完整创作及扩展流程、保存失败恢复、候选采用、审核、导出、设置保护、大纲操作、跨文章延迟响应，以及 1440／1100／390px 下七个页面。

本次真实验收只创建独立测试文章，使用现有选题配置，付费请求上限为 10（包含工具内付费请求），连接、权限或额度错误立即停止。实际发出 10 次模型请求，均收到响应；未复现本轮之前的超时或 HTTP 429。模型尚在读取资料和调用工具，未在限额内产出候选，达到上限后结束，没有追加请求或切换模型。费用仍为未知，不能记作零；本次不能宣称真实选题已经跑通或外部服务已稳定恢复。

真实文章、配置与凭证没有因验收而改动。个人数据、原始诊断和截图只保留在本地忽略目录。发布包含预构建界面，后台版本从 `package.json` 读取；已核对本工作区实际服务为 v2.3.0、页面入口和资源与构建逐字节一致，重复启动复用原进程；切换时无活动任务，原有文章、历史、设置及凭证与验收前一致。已打开的旧页面需要刷新。
