# v2.3.5 用量上限与联网搜索修复

工作台不再按请求、工具、费用、搜索、读取或补查轮数中断任务。达到证据充分、没有新查询或没有实质进展时，研究仍会结束；用户也可手动停止。次数、Token、已知和未知费用继续记录。旧配置、文章和历史任务中的限额字段可读取，但不再参与执行。

服务中填写的输出 Token 参数直接交给所选接口校验；联网搜索使用同一参数，不再固定为 2000 Token，也不向原生搜索工具附加内部次数上限。搜索工具已经返回有效网址、但文字因输出参数截断时，网址只作为待读原文的线索，搜索诊断会显示“回复不完整”。工具报错、拒答、无有效来源仍失败，也不重发失败的付费请求。

节点模型负责执行 WeWrite 技能、决定何时搜索并整理结果；联网模型负责返回真实搜索来源。两者可以使用同一服务，也可分配不同服务。界面会显示“选题”“素材分析”“检索规划与整理”“联网搜索”各自实际使用的服务。上游 WeWrite 技能本身和排版导出控件未改。

定向模拟检查覆盖 72,000 Token 保存与搜索接口透传、超过旧请求／工具／搜索／读取阈值、截断且有真实来源、无效来源、工具错误、取消、用量记账和旧配置兼容。受影响的模拟测试共 262 项通过；前端生产构建通过。没有进行真实付费模型调用，因此不能据此认定外部服务稳定或真实选题和素材任务已完成。按本次额度约束，未运行全量验收。

实际工作区切换前核对无活动任务，随后通过启动器安全切换到 v2.3.5。健康接口的运行版本与可用版本均为 v2.3.5；首页及全部三个预构建资源与磁盘文件逐字节一致。再次运行启动器后复用同一后台进程。已有页面需要刷新以加载新界面。
