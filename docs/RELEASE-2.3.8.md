# v2.3.8 功能入口按使用场景归位

顶部“扩展”及统一的“创作扩展”弹窗已移除。自定义人格位于写作设置的人格选择旁；排版学习位于主题下拉框旁；多平台改写与微信文章、图片帖草稿推送位于排版导出。原主题下拉框、颜色圆点、参数输入和手机预览保留。

“账号与学习”继续使用原入口和弹窗。公众号连接放在账号定位内，在线效果与复盘并入效果记录。推送窗口可跳到公众号连接，关闭账号弹窗后返回原输入；公众号连接、摘要或文章变化后需要新的有效预览，明确点击才会推送。新主题和人格加入原选项，由用户选择应用。

各功能独立展示自己的任务、成果和回执。任务记录先按功能、文章筛选再分页，兼容过去挂在文章下的排版学习任务；活动任务在历史翻页时仍可查看。关闭、重开与刷新可以恢复已保存成果，切换文章后的迟到响应不会串入当前窗口。正在等待预览时修改输入，会丢弃该次旧预览。

本版继续使用固定的上游 WeWrite 4.2.1 及原执行接口，不改变账号学习规则，不迁移个人数据。账号定位说明为后续任务的长期参考，本篇要求优先。范文确认、效果记录的整小时限制与修改方式、学习规则生效显示及适用范围等问题留待后续处理，详见 [账号流程检查](ACCOUNT-WORKFLOW-REVIEW.md)。

验证使用临时模拟数据与模拟网络／模型：

- 相关后端回归 57 项通过，包括先筛选后分页、旧排版任务、文章隔离、活动记录及恢复回执。
- 前端类型检查和生产构建通过。浏览器完成所有迁移功能的桌面与手机交互，验证输入保存、选项刷新、任务关闭重开与刷新、公众号连接往返、预览过期、明确推送、图片帖、草稿副本、在线效果与复盘。
- 模拟慢响应、服务失败和取消，验证旧成果保留、迟到结果归属和不自动重发；补充预览等待期间修改摘要的回归。
- 原有完整创作流程、账号学习／历史／范文／手动指标／使用记录及编辑、保存与恢复检查通过。
- 原首页、七个创作环节、弹窗、键盘焦点和任务提示在 1440、1100、390 三种窗口宽度下的视觉与交互回归通过。

应用版本、锁文件、后端读取版本和预构建 `dist` 已同步。实际工作区无活动任务时，启动器安全切换到 v2.3.8；再次启动复用同一后台，实际提供的五个界面文件与构建产物逐字节一致。文章、历史版本、设置、凭证及账号记录切换前后校验一致。已有页面需刷新以加载新界面。

本次没有调用真实付费模型或向真实公众号推送。个人文章、凭证、数据及本地诊断记录不进入发布仓库。
