# v2.3.1：首页恢复与视觉精修

首页恢复为 v2.2.0 的完整构图：两行大标题、介绍文案、纸张插画、浮动便签和底部三步引导。文章数量不再触发压缩首页。

全站沿用米白、深绿与纸张感，保留七阶段、右侧栏及排版导出的下拉框、颜色圆点、参数输入和手机预览。字号、控件、表单及留白按用途统一，主要操作与辅助信息分层。

## 交互调整

- 选题的主题输入、探索要求和生成按钮集中在同一区域；生成候选与采用主题保持独立。
- 内容状态与任务提醒分离；已采用主题不再保留旧任务的“待你确认”。模型配置来源和执行记录展开查看，重复前置条件提醒合并。
- 素材核实记录按需展开；大纲标题与章节内容优先，排序、依据和删除分组，保留折叠与撤销。
- 整体编辑和人工定稿收为正文附近的操作栏，说明与稿件记录展开查看；审核保留待处理意见优先。
- 手机保留可读的阶段名称，主要触控区域至少 44px；菜单、编辑工具栏和弹窗关闭后的焦点返回经过检查。

## 验收

- 类型检查与生产构建。
- 完整离线创作流程：账号、扩展、整体编辑候选采用／放弃、人工定稿／恢复、保存失败保护、资料处理、引用、配图、预览与导出。
- v2.3 回归：输入草稿、失败恢复、重试阶段、设置保存保护、大纲移动／删除撤销、自定字数、跨文章响应隔离及选段修改。
- 新增 `tools/check_ui_visual_v231.py`，覆盖 1440、1100、390px 下首页、七阶段、设置、账号、扩展、侧栏及任务状态。检查空库与已有文章的首页布局一致、搜索空状态、长标题、导航名称、焦点返回、触控尺寸和横向溢出。
- GitHub Windows acceptance 同时执行后端测试、构建产物一致性和三组浏览器验收。

测试使用独立模拟数据，禁止外部模型请求。本版新增付费模型调用为 0；没有修改后端接口、文章结构、模型分配或个人文章。模拟检查不用于判定外部选题服务是否恢复。

发布后核对实际服务版本、页面资源和启动器复用。已打开的旧页面请在保存后刷新。
