# v1.6.0：证据状态与来源核实

这是四批公众号质量优化的第一批。核心问题现在有稳定任务书和逐项覆盖记录，继续创作与证据充分分别表达。原文引文匹配后再独立检查人群、设计、数字分母、结局、因果及适用范围；作者解释和转引不能作为本研究实测结果。

## 改动
- 修正核心引文失败降为普通局限、完整问题列表吞掉其他缺口、背景证据触发提前完成等路径。单问题核实不会宣布整篇核实完成。
- 搜索候选与全文副本再次核对身份，静态页面与动态页面统一区分摘要/全文，结构化长摘要仍为摘要。
- 缓存包含分析模型、政策、输出结构和研究实现版本；旧证据无独立判断时显示待复核。保留旧文章、引用编号和人工决定。
- 资料页增加核心/补充问题及支持、有限支持、反证、未解决状态。排版下拉框、颜色圆点、参数和手机预览保留。
- 首次保存前额外创建并校验 `data/backups/before-quality-evidence-v1.sqlite`。这是数据库副本，不含附件；回退前应另行完整备份数据和附件。

## 验证
- 后端 286 项模拟测试通过，包括新增 19 项证据反例；测试禁止外网。
- TypeScript 与正式前端构建通过；编辑器原有大包提示保留。
- 完整离线浏览器流程通过：资料、大纲、写作、审核、导出、保存冲突、排除/撤销、检索上限、长原文、键盘及多种窗口宽度。
- 使用现有研究模型执行四项合成语义反例：错误因果、错误分母、把机制假设冒充实测均未通过；正确对照陈述通过。该验证不证明真实文章不存在事实错误。
- 开发过程的两个真实定位试运行找到 ACL 和长上下文目标来源；它们不作为最终跨领域质量验收。
