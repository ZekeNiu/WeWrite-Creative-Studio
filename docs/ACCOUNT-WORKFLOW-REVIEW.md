# 账号与学习：流程检查与本版边界

本次检查以项目固定的 WeWrite 4.2.1 为依据。v2.3.8 保留“账号与学习”入口、弹窗及现有执行规则，仅调整功能位置与提示。

## 本版入口

人格管理位于写作设置的人格选择旁；排版学习位于排版主题旁。多平台改写、微信文章及图片帖草稿推送、回执与草稿副本放在排版导出。公众号连接放在账号定位内，在线效果与复盘放在效果记录内，与手动记录共用关联文章选择。

账号定位的受众、方向、表达和禁用事项是后续任务的长期参考。本篇任务书及补充要求优先，保存账号参考不会自动重写已经生成的文章。本版不将这四项扩展为新文章的完整默认配置。

## 上游机制与工作台附加规则

| 项目 | 当前依据与行为 | 后续可处理的问题 |
| --- | --- | --- |
| 人工改稿学习 | 上游比较 AI 原稿与人工终稿，按模式、适用范围、重复次数及时间计算置信度；明确确认或满足上游重复条件时可成为固定规则。工作台负责记录真实改稿对、栏目筛选与停用决定。 | 界面的“软参考”主要显示工作台保存状态，未完整展示上游实际生效强度；编辑文本时移除上游模式，可能丢失原来的适用条件。后续应统一展示与实际执行范围。 |
| 范文 | 上游提取真实表达片段，保留所有权信息，只参考风格与结构；工作台另外要求导入后再次确认才启用。 | 可考虑将明确导入与启用合并，但需保留旧待确认、停用及撤销记录的用户决定。 |
| 手动效果记录 | 工作台要求观察时间相差整小时；修改需删除重录。自动描述按栏目与相同观察窗口分组，每项指标至少五篇已知样本才显示摘要。 | 整小时与删除重录属于额外交互限制；五篇门槛限制的是自动摘要，并不阻止记录数据。这些不应误称为上游要求。 |
| 效果复盘 | 执行上游 wewrite-stats 并读取账号历史；当前适配层仍要求选择关联文章，复盘结果归入该文章任务记录。 | 上游可基于账号历史复盘；解除文章依赖需要单独调整任务上下文及成果归属，本版不改。 |
| 账号定位 | 工作台将长期参考与本篇参数投影到上游 style.yaml，并保留实际发送给模型的参考快照。 | 当前并非完整的公众号默认配置；界面明确其作用，本版不增加账号名称、默认人格、署名或排版等设置。 |

## 继续保留的保护

公众号凭证在本机加密，不进入模型上下文。推送需明确操作，并绑定当前文章版本、预览和连接；微信请求不自动重试，取消或中断时保留已获得的回执。在线效果依靠明确的微信统计文章编号关联，未知值不补零。学习所需的真实人工改稿对、版本冲突保护和第三方范文的使用边界继续保留。

这些记录用于后续讨论。v2.3.8 没有修改范文确认、指标窗口与摘要门槛、学习算法、适用范围编辑或账号复盘的文章依赖。
