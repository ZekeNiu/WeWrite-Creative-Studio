# v2.3.7 素材自动收尾与增量核实

素材页的“查找并整理资料”及共用定向核实链路，现在围绕用户要求和已采用选题中的固定问题推进。每批搜索、候选阅读、原文回读和引用追踪后检查问题是否得到回答；已完成的问题停止扩展。继续取证需要绑定具体问题、目的和渠道，换措辞、重复材料或新增数量本身不能维持循环。未继续读取的候选保留在任务记录中。

新增、改变或定向补读的材料只生成相关候选，与未改变的已核实证据合并。独立引文定位、主张支持、适用条件和问题覆盖核查继续保留。复用绑定实际来源内容、访问范围、主张、边界及核查版本；相关反证会重新打开问题，包括定向核实中受到影响的其他问题。筛选与独立核查只携带对应来源及必要上下文，重复章节请求不再轮换成“新阅读”。

没有有效补查方向时保存核实成果、缺口、尝试记录和结束原因，任务进入待处理状态，停止自动续行。完成某一项核实不代表整篇资料充分。缺口保持未解决，“未找到”不会自动当成反证或改写成保守结论。失败或取消后，新任务可复用仍有效的核实检查点；用户已修改的依据重新核实，已删除的材料不因恢复而重新加入。

素材页沿用原布局，显示正在核实的问题和结束原因，继续通过现有补材料、逐项核实入口处理。新增记录字段为可选项，旧任务兼容读取。服务输出参数、上游创作技能及排版导出界面保持原有配置。

验收使用合成资料和模拟服务，不调用付费模型，不运行个人文章。版本同步应用配置、锁文件、后端读取版本及预构建界面。

后端全量回归 **691 项通过**，其中新增 23 项收敛、增量核实与恢复测试，并补充定向核实后仍有其他缺口的交接场景。覆盖充分后停止剩余渠道、无进展时保留候选、换措辞去重、来源或边界变化失效、相关反证重新打开问题、失败或取消保留检查点，以及用户删除材料后不被恢复。现有独立质量核查回归继续通过。

前端生产构建通过。浏览器验证涵盖素材不足交接、补材料后收尾、运行中的具体问题、停止自动进入大纲、桌面与手机宽度，以及原有创作流程、任务可靠性、视觉布局和模型设置。新增收敛交互验收已加入 GitHub Windows 验收流程。

实际工作区确认无活动任务后，启动器已将后台安全切换到 v2.3.7。运行版本和可用版本一致，提供的 5 个界面文件与预构建产物逐字节相同，再次启动复用同一后台。文章、历史版本、设置和凭证记录的切换前后校验一致。旧页面需刷新以加载新版界面。
