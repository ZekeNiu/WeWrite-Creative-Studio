# v2.4.2：保护文章的主线与阅读节奏

本版让素材、大纲、写作和编辑共用集中维护的创作规则：内部核查帮助模型写准主张，文章按原本的内容持续展开。减少没有新增信息的免责说明，保留推动论证的反方、具体条件、类比和作者声音。

- 大纲区分读者内容与作者提醒；旧大纲中的写作指令按约束理解，避免进入正文。
- 初稿和编辑从整篇论述检查段落承接；修正过宽说法时直接修改原句，再检查上下文。
- 事实核查按自身任务目的构建提示，沿用原模型配置；创作规则不会注入独立事实核查。
- 原生入口与兼容入口共用规则，并记录规则版本和摘要。继续使用固定上游技能、现有审稿轮次及修改候选机制。
- 成稿对照工具默认走当前生产使用的原生流程，使用冻结材料、模型配置及账号上下文；基线与候选执行相同阶段。
- 修复模型按当前任务目录读取原文时的路径兼容问题，两种路径指向同一份只读资料，读取记录保留规范路径。

规则与验证维护方法见 [维护说明](https://github.com/ZekeNiu/WeWrite-Creative-Studio/blob/v2.4.2/docs/WRITING-GUIDANCE.md)。界面与文章字段无需迁移，历史文章在再次执行对应环节时使用新规则。

两题样本支持本次改动对连贯性与事实表达的改善；这不是跨模型、跨选题稳定通过率的证明。工程接入置信度高，写作效果置信度中。
