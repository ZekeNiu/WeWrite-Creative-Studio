# v1.8.0：论证综合与整体编辑

第三批把大纲前的论证整理、正文独立事实核查和整体编辑接入现有创作流程。整体编辑先保存候选，再核查和展示差异；作者可以采用或拒绝，人工定稿与AI审核结论分别记录。

## 功能

- 大纲前形成核心判断、支持链、最强反方、冲突与适用边界，验证论证引用的来源与证据编号。
- 按段核对数字、研究结论、引语和未标引用的重要事实。原文定位与独立判断分别保留，未知检查值按未核实处理；五项编辑评分不能覆盖事实问题。
- 整体编辑可以重组章节和论证，保留原稿、完整候选和差异。自动编辑最多两轮，有新的事实问题时不会自动覆盖原稿；并发人工编辑使旧候选不能直接采用。
- 初稿、AI编辑稿和人工定稿分开保存，明确记录实际人工修改对应的AI原稿。单纯点击定稿不会制造人工改稿学习对，也不会把AI未通过的审核改为通过。
- 合入v1.7.0最终研究修正。按一轮问题和每两条延期来源集中评估，正文审核直接调用已有独立事实核查，不先重跑完整研究。删除重复阶段规则，表达要求不再成为资料缺口，事实核查不接收旧AI自评。
- 明确公众号文章的表达目标：必要限定自然融入句意，不把正文变成核查报告，不为免责改变用户主题、语气或论证。删除上游命令行文件创建和重复自动交付指令，保留编辑原则、人格与结构参考；机制、反方和局限不强制各成一节。论证缓存版本随提示调整更新。
- 保留引用统一编号、人工修改、历史恢复、排版下拉框、颜色圆点、参数输入与手机预览。
