# v2.2.0：上游独立扩展

三批原生化改造的最终功能批次。v2.0.0 接入真实技能和多轮工具执行；v2.1.0 统一学习、范文和粘贴排版；v2.2.0 提供其余上游能力的独立入口。

## 本批变化

主题学习复用上游原始样式提取；自定义人格以完整上游文件为基础，进入原选项。原来的下拉框、颜色圆点、参数和手机预览保留。

小红书和抖音改写读取完整模块及平台规范，保留不可改写的源稿，运行真实 score / similarity；最多两次重试，未通过保留待处理版本，平台稿可独立下载。

公众号文章和图片帖通过单独动作进入草稿箱：先核对当前预览，封面独立，使用上游上传和建草稿函数。当前 HTML 保留用户主题和字号，空摘要采用上游生成结果。没有正式发表接口，没有写作／完整制作自动推送。远端草稿只作为副本读取，不自动推定人工偏好。

微信凭证加密保存，通过子进程标准输入提供，不给模型。动作绑定版本与凭证，幂等编号阻止同一请求重放；中断不自动重试。取消等待已发送请求回执，后台重启阻止继续发送，迟到结果也可恢复。若远端结果未知，先核对公众号后台。

在线效果复用上游统计读取，按明确 msgid 关联文章，保留未知和原始返回，不采用标题兜底或缺失补零。线上与手动效果投影到原生历史，可独立运行上游数据复盘。阅读与结构建议也转为原生执行，删除默认调度中的旧创作与重复编辑分支。

## 验证与边界

- 正式目录573项用例。全量572项通过；随后增加恢复测试，并对扩展、原生执行、恢复、排版和账号相关模块完成定向复核（最终检查56项通过）。
- TypeScript／前端构建通过。完整离线浏览器流程通过；最终2.2.0界面再次验证人格、主题、平台稿、文章／图片帖草稿、远端副本、效果回填与复盘，以及桌面／手机宽度。
- 模拟的只是模型和网络返回。上游文件、工具循环、命令、评分、相似度、状态和界面实际执行。微信底层函数以模拟HTTP验证，不进行真实账号推送。
- 本轮新增付费模型请求0。现有中转文本价格为空，未能核实价格；真实质量对照仍待准确价格，不能据离线通过宣称文笔已经等同或优于纯上游。原计划诊断限额8次／20元没有写成永久默认值。
- 无个人文章、凭证、data、output或本地诊断进入提交。当前服务和启动器在交付时单独核对；旧页面请刷新。
